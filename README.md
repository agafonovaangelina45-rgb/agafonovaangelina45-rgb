# Портфолио Ангелины Агафоновой

Адаптивный сайт-портфолио на чистых HTML, CSS и JavaScript.

## Дизайн

Выбран стиль **1 — Nordic Lagom Corporate Minimalism**: молочный фон, светлый серо-зелёный, графитовый текст и приглушённый сине-серый акцент.

## Файлы проекта

- `index.html` — содержание и структура сайта.
- `style.css` — цвета, оформление и мобильная адаптация.
- `script.js` — мобильное меню и автоматический год в подвале.

## Как открыть сайт

1. Скачайте и распакуйте архив.
2. Откройте папку `angelina-portfolio` в VS Code.
3. Откройте файл `index.html` в браузере. Также можно использовать расширение Live Server, если оно уже установлено.
4. Чтобы изменить текст, откройте `index.html` и найдите нужный раздел.
5. Чтобы изменить цвета или размеры, откройте `style.css`.

Сайт не требует установки npm-пакетов, сборки или сервера. Шрифт загружается из Google Fonts; если интернета нет, будут использованы системные шрифты.

## Публикация на GitHub Pages

1. Создайте новый репозиторий GitHub.
2. Загрузите в него `index.html`, `style.css`, `script.js` и `README.md`.
3. Откройте **Settings → Pages**.
4. В разделе публикации выберите ветку `main` и папку `/ (root)`, затем сохраните настройки.
5. Дождитесь завершения публикации и откройте ссылку, которую покажет GitHub Pages.

Публикация не выполняется автоматически. Перед размещением проверьте, что вы действительно хотите сделать адрес электронной почты общедоступным.
